CONTRIBUTE

Change the right layer. Prove it still works.

Raz is split across independently owned components, but compiler correctness, determinism and synchronized integration are shared project contracts.

Canonical contributing guide ↗Ecosystem map

OWNERSHIP

Start in the canonical repository.

Do not work around a language/compiler problem in another layer. Make the change where the behavior is owned, then synchronize integration copies when required.

raz

Language + compiler

Language semantics, HIR/MIR, CLI/project driver, runtime boundaries and LSP integration.

forge

Native backend

Forge IR, optimization, machine lowering and standalone backend tools.

oblink

Native linker

Object/link behavior and linker-specific platform support.

packages

Registry packages

Official package sources, versions and registry index state.

installer

Distribution

MSI, portable archives, channel manifests and release packaging.

raz-vscode

Editor UX

BASELINE CHECK

Normal compiler work.

The Raz contribution guide requires a debug configure/build/test cycle, plus focused checks that match the subsystem being changed.

compiler repository
cmake --preset debug
cmake --build --preset debug
ctest --preset debug

EMBEDDED COMPONENTS

Forge and ObLink are mirrors, not forks.

Make maintained component changes in the standalone repository first, then synchronize the embedded copy carried by Raz and verify byte identity.

synchronize integration copies
python tools/sync-embedded-components.py
python tools/check-embedded-components.py
01

Language behavior belongs in Raz

Do not move semantics into native shims because the language implementation is harder.

02

Preserve determinism

Source discovery, dependency ordering, generated identifiers and compiler output must remain reproducible.

03

Qualify the whole affected path

A feature is not complete merely because it parses; test semantic, MIR, backend and execution behavior where applicable.

04

Keep generated state out

Build products, caches and project targets are generated state rather than source.
