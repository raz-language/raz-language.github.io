Using the portable ZIP

Extract the archive, then run its bundled installer script. It registers the portable toolchain for the current user.

PowerShell
Expand-Archive ./raz-1.0.0-windows-x86_64.zip -DestinationPath .
& ./raz-1.0.0-windows-x86_64/install.ps1

Install the Linux archive

The archive contains install.sh. It installs under ${XDG_DATA_HOME:-~/.local/share}/raz and creates managed command links in ~/.local/bin without editing shell startup files.

shell
tar -xzf raz-1.0.0-linux-x86_64.tar.gz
cd raz-1.0.0-linux-x86_64
./install.sh
raz --version
raz doctor

If raz is not found afterward, add ~/.local/bin to your shell PATH.
