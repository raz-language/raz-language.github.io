WHY RAZ

Control where it matters.
Proof where it helps.

Raz keeps the systems-programming cost model explicit while moving ordinary memory-safety work into the compiler.

01

Visible cost model

No mandatory tracing garbage collector and no hidden runtime ownership model. Moves, borrows, monomorphization, dispatch and unsafe boundaries are visible decisions.

02

Ownership safety

Ownership, moves, non-lexical borrowing, bounds-aware slices and deterministic destruction give low-level programs a safer default path.

03

One semantic pipeline

Source is analyzed once into typed HIR and verified MIR. Forge, LLVM, WebAssembly and RXE consume semantics that are already settled.

04

Tooling with the language

Builds, tests, formatting, docs, packages, workspaces, diagnostics and the language server share the compiler's semantic engine.
