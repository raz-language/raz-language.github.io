Key ideas#

  • Keep extern, raw pointers, casts, and C ABI boundaries small, explicit, and auditable.
  • Keep cost and ownership decisions visible in source
  • Use compiler diagnostics as part of the development loop

Example#

raz
extern fn native_call(i64 value) -> i64;

fn call_native(i64 value) -> i64 {
    unsafe {
        return native_call(value);
    }
}
