PORTABLE TARGETS

WebAssembly and RXE from the same verified MIR.

Raz can leave the native host without changing frontend semantics: WebAssembly targets a documented ABI, while RXE targets a specified portable bytecode format.

WEBASSEMBLY

.wasm

Portable WebAssembly output under the documented Raz Wasm ABI. Use it when a browser or non-browser Wasm host is the execution environment.

RXE

.rxe

A portable bytecode target with a specified file format and instruction set for runtimes and tools that do not want native machine code.

SHARED SEMANTICS

Backend-neutral by design.

Ownership, type checking, conversions and language semantics are resolved before target-specific code generation. Portable targets do not introduce a second language mode.
