PROJECT MODEL

raz.toml, raz.lock, and predictable artifacts.

A Raz package declares its package metadata and dependencies in raz.toml. Registry constraints resolve to exact lockfile entries, and normal builds place artifacts under consistent profile directories in target/.

CLI

One driver for the development loop.

raz new · initCreate or initialize packages.
raz checkParse, resolve, type-check and validate.
raz build · runBuild artifacts and execute packages.
raz test · lintRun tests and semantic validation.
raz fmt · docFormat source and generate API docs.
raz doctor · backends · targetsInspect the toolchain and target support.

PACKAGES

Deterministic packages and lockfile resolution.

The official registry is GitHub-backed. Package archives are immutable and content-addressed, while builds can hydrate locked dependencies automatically from a clean checkout.

EDITOR TOOLING

The language server uses the compiler's semantic engine.

raz lsp provides diagnostics, project indexing, semantic navigation, rename, hover, signatures, tokens, inlay hints, completion, formatting, code actions, folding and selection ranges.

VS Code extension ↗

C INTEROPERABILITY

Explicit ABI tooling.

raz bindgen generates supported C ABI declarations, while raz c-header emits C declarations for explicitly exported Raz C-ABI APIs.
