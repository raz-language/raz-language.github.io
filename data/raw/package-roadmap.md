# Official Package Roadmap

| Order | Package | Status |
|---:|---|---|
| 1 | `crypto` | **0.4.0 crypto core implemented** |
| 2 | `serde` | **0.2.0 core contracts implemented** |
| 3 | `toml` | **0.2.0 parser/document core implemented** |
| 4 | `regex` | **0.2.0 Thompson/Pike NFA engine implemented** |
| 5 | `uuid` | **0.2.0 RFC 9562 v4/v7 core implemented** |
| 6 | `semver` | **0.2.0 SemVer parser and requirement engine implemented** |
| 7 | `datetime` | **0.2.0 civil time, timestamps, durations, UTC offsets, and RFC 3339 implemented** |
| 8 | `websocket` | **0.2.0 RFC 6455 protocol core implemented** |
| 9 | `http-router` | **0.2.0 compiled allocation-conscious router implemented** |
| 10 | `sqlite` | **0.3.0 client implemented** |
| 11 | `postgres` | **0.3.0 PostgreSQL v3 client implemented** |
| 12 | `jwt` | **0.1.0 HS256 JWS, registered claims, and symmetric JWK implemented** |
| 13 | `multipart` | **0.1.0 bounded form-data reader and writer implemented** |
| 14 | `archive` | **0.1.0 safe TAR and stored-ZIP core implemented** |
| 15 | `testing` | **0.1.0 assertions, deterministic properties, and benchmark statistics implemented** |
| 16 | `encoding` | **0.1.0 hex, Base64url, Base32, and checksum APIs implemented** |
| 17 | `json` | **0.1.0 strict parser facade, document, pointer, and writer APIs implemented** |
| 18 | `csv` | **0.1.0 streaming reader and bounded writer implemented** |
| 19 | `yaml` | **0.1.0 bounded block-style YAML core implemented** |
| 20 | `cbor` | **0.1.0 allocation-free RFC 8949 codec implemented** |
| 21 | `msgpack` | **0.1.0 allocation-free MessagePack codec implemented** |
| 22 | `protobuf` | **0.1.0 Protocol Buffers wire codec implemented** |

Future candidates include `oauth2`, `graphql`, `rpc`, `metrics`, `tracing`, `quic`, `dns`, `mmap`, `uring`, `base58`, `bech32`, `secp256k1`, `merkle`, `rlp`, and `ssz`.
